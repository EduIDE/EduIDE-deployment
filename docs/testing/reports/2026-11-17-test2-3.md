- New test LOG-01 (prod-safe): read operator, service, webhook and landing page logs from the start and classify WARN and ERROR (JDK, TLS, permission, other); table as in this report.

- Changed expectation: PLAT-01: cluster chart and `eduide` chart may differ in a release candidate rollout; record both.
- New Explore ideas: repeat release 20 times and count `Failed to clean up deployment` (F37); count webhook conversions per minute per target version for 10 minutes on an idle environment (F38); `--sun-misc-unsafe-memory-access=allow` to remove the Unsafe warnings.
